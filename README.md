# 📦 프롬프트 상자

프롬프트를 저장해두고 바로 복사해 쓰는 개인용 도구 → https://stella-l.github.io/prompt-box/

- 제목 · 프롬프트 · 출처 · 태그 · 메모 저장
- 원클릭 복사, `{{빈칸}}` 채워서 복사
- 즐겨찾기, 태그 필터, 검색 (`/`)
- 구글 시트에 저장 → 어느 기기에서나 같은 목록

## 구글 시트 연결

처음 한 번만 하면 돼요. (5분)

1. [새 구글 시트](https://sheets.new)를 만들고 이름을 `프롬프트 상자`로 바꿔요.
2. 메뉴 **확장 프로그램 → Apps Script**를 열어요.
3. 기본 코드를 모두 지우고 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 붙여넣어요.
4. 맨 위 `TOKEN` 값을 나만 아는 긴 문자열로 바꾸고 저장(⌘S)해요.
5. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱**을 선택하고
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포** → 권한 승인 (*고급 → 안전하지 않은 페이지로 이동*을 눌러 허용해요. 내가 만든 스크립트라 괜찮아요)
6. 나온 **웹 앱 URL**(`…/exec`)을 복사해요.
7. 프롬프트 상자 왼쪽 위 **이 브라우저** 버튼(또는 ⋯ → 구글 시트 연결)을 누르고 URL과 토큰을 입력해요.

> 토큰은 저장소에 올리지 마세요. 웹 앱은 URL과 토큰을 둘 다 아는 사람만 읽고 쓸 수 있어요.

### 참고

- 시트에서 직접 줄을 추가해도 돼요. `프롬프트` 칸만 채우면 다음 새로고침 때 앱에 나타나요.
- 앱은 탭으로 돌아올 때, 그리고 1분마다 시트 내용을 다시 불러와요.
- `Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영돼요. (URL은 그대로예요)
